### FPC 引脚定义（从左到右，正面看）

| 引脚 | 名称    | 功能说明       | 连接 BK7252N |

| 2    | GND     | 地             | GND          |
| 3    | CS      | 片选           | GPIO6        |
| 4    | RESET   | 复位           | GPIO10       |
| 5    | DC      | 数据/命令      | GPIO9        |
| 6    | SDO     | SPI 输出 (MISO) | 悬空         |

| 8    | SDI     | SPI 输入 (MOSI)| GPIO8        |

| 10   | LED_K   | 背光阴极       | GND          |

## 软件配置

### 1. 启用 LCD 驱动

使用 menuconfig 启用：
```bash
scons --menuconfig

# 导航到：
Hardware Drivers Config  --->
    [*] Using SPI Master  --->
        [*] Using ST7789 LCD Driver
```

或者手动修改 `rtconfig.h`，添加：
```c
#define BEKEN_USING_ST7789_LCD
```

### 2. 编译和烧录

```bash
scons
scons --download
```

### 3. 测试命令

烧录完成后，通过串口连接，使用以下命令测试：

```bash
# 初始化 LCD
st7789_lcd_init

# 运行测试（清屏、显示文字、画图形）
lcd_test

# 控制背光
lcd_bl_on
lcd_bl_off
```

## 引脚修改

如果 GPIO6-11 已被其他功能占用，可以修改 `drivers/drv_st7789_lcd.c` 中的引脚定义：

```c
/* 可用引脚范围：GPIO6 - GPIO27 */
#define LCD_CS_PIN      GPIO6   /* 必须是 SPI0 CS */
#define LCD_CLK_PIN     GPIO7   /* 必须是 SPI0 CLK */
#define LCD_MOSI_PIN    GPIO8   /* 必须是 SPI0 MOSI */
#define LCD_DC_PIN      GPIO9   /* 任意 GPIO */
#define LCD_RST_PIN     GPIO10  /* 任意 GPIO */
#define LCD_BLK_PIN     GPIO11  /* 任意 GPIO 或 PWM */
```

**注意：**
- CS、CLK、MOSI 必须使用硬件 SPI0 引脚（GPIO6-8）
- DC、RST、BLK 可以使用任意 GPIO

## 常见问题

### 1. LCD 不显示

**检查：**
- VCC 电压是否为 3.3V
- CS 引脚是否正确连接
- RST 引脚是否正确复位
- 背光是否点亮（LED_A 是否有电）

**解决：**
```bash
# 测量背光引脚电压
# 如果背光不亮，可以临时直接连接 3.3V 测试
```

### 2. 显示花屏

**检查：**
- MOSI 信号线是否接触良好
- SPI 时钟频率是否过高

**解决：**
修改 `drv_st7789_lcd.c`，降低 SPI 速度：
```c
cfg.max_hz = 10 * 1000 * 1000;  /* 从 20MHz 降到 10MHz */
```

### 3. 显示方向不对

**解决：**
修改 `drv_st7789_lcd.c` 中的初始化序列：
```c
/* 内存数据访问顺序 */
lcd_write_cmd(0x36);
lcd_write_data(0x00);  /* 尝试不同值：0x00/0x20/0x40/0x60/0x80/0xA0/0xC0/0xE0 */
```

### 4. 颜色不对

**解决：**
启用/禁用显示反转：
```c
/* 在初始化序列中 */
lcd_write_cmd(0x21);  /* 启用反转 */
/* 或 */
lcd_write_cmd(0x20);  /* 禁用反转 */
```

## 接线材料

推荐使用以下材料连接：

1. **杜邦线**：母对母 或 公对母（根据实际接口）
2. **排阻**：10-50Ω（用于背光限流）
3. **万用表**：测量电压和通断

## 注意事项

1. **电源电压**：确认显示屏工作电压为 3.3V，不要接 5V
2. **静电防护**：接触显示屏前释放静电
3. **FPC 插拔**：轻轻插拔，避免损坏座子
4. **背光限流**：LED_A 必须串联电阻（10-50Ω）
