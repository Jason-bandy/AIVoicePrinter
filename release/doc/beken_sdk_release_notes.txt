BEKEN SDK 3.0.7 release notes:
1. The RT-thread OSK which matches SDK 3.0.7 is OSK R-3.0.6;
2. Separate RF sleep code from other modules;
3. Fix the connection interupted and assert issue caused by airkiss;
4. Fix the 'ps_level 3' sleep failure issue after channel scan;
5. Fix the issue that 'wifi w0 down' fail after sta connection is deleted;
6. Fix mac_vsie_find:94 assert issue;
7. Fix Ble adv start issue in the case of Ble adv start twice;
8. Fix the association issue with one new ASUS WiFi6 router;
9. Fix one 'data abort' issue when do associaton quickly and frequently;

BEKEN SDK 3.0.3 release notes:

1. Beken378 is BEKEN SDK directory, the other directories are OSK directoies;
2. The RT-thread OSK which matches SDK 3.0.3 is OSK R-3.0.3;
3. It is the initial release which support BK7231N;
4. The libraries included with this release are built with the default sys_config.h
   file, if you change sys_config.h with your build, for example, enable WPA3 or
   PMF, the IP librarys may not work, please contact BEKEN for your configuration.
5. This release provide WiFi and Ble functionality, and a series of peripheral
   interfaces, for the detailed APIs, please see the API document.
